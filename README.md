# Тыква со стола

Интерактивная 3D-тыква для экспериментов с резьбой к Хэллоуину. Форма сделана по фотографиям настоящей тыквы.

## Что умеет

- Вращать и приближать модель пальцем или мышью.
- Рисовать прямо по поверхности:
  - **Прорезать**: сквозная дырка, через неё светит свеча.
  - **Соскоблить**: кожура снята, стенка остаётся и светится мягче.
  - **Ластик**: возвращает кожуру.
- Готовые шаблоны: «Классика», «Злая», «Летучие мыши», «Кот на луне».
- Режим «Ночь» с мерцающей свечой; свет через узор падает на стол и стену.
- Настройка формы: число рёбер, глубина бороздок, пропорции, ямка у хвостика, неровность, хвостик, цвет.
- Узор и форма сохраняются в `localStorage` браузера.

## Запуск

Опубликовано на GitHub Pages: https://irudakov.github.io/pumpkin-carving/

Локально:

Это одна страница без сборки. Откройте `index.html` в браузере или поднимите любой статический сервер:

```sh
python3 -m http.server 8000
```

Three.js r128 и OrbitControls подключаются с CDN.

## Как устроено

- Тело тыквы строится процедурно в сферических координатах: рёбра, ямки у полюсов, шум для неровностей.
- Рисунок кожуры генерируется на canvas (шум Ворли для сеточки плюс value noise для пятен).
- Резьба хранится в двух canvas-масках в UV-пространстве тела: маска прорезей (`alphaMap` + `alphaTest`) и маска соскоба (`emissiveMap`).
- Внутренняя стенка повторяет форму в масштабе 0.92 с теми же масками, точечный свет внутри отбрасывает тени через прорези.
